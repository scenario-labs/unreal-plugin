# Support

Scenario for Unreal Engine is an open-source editor plugin maintained by
Scenario. This page says where to look and whom to ask.

## Using the plugin

- Start with the [user guide](docs/USER_GUIDE.md), the
  [quick start](docs/QUICK_START.md) and
  [Troubleshooting](docs/TROUBLESHOOTING.md). Agents and the local Scenario MCP
  server are covered in the [MCP guide](docs/MCP_GUIDE.md).
- For models, Creative Units and account settings, see the
  [Scenario Knowledge Base](https://help.scenario.com).
- For release changes, read the [changelog](CHANGELOG.md) and the
  [releases](https://github.com/scenario-labs/unreal-plugin/releases);
  the open [Bug issues](https://github.com/scenario-labs/unreal-plugin/issues?q=is%3Aissue%20is%3Aopen%20type%3ABug) list current limitations.

## Bugs, change requests and questions

Use the [issue chooser](https://github.com/scenario-labs/unreal-plugin/issues/new/choose).
Search the [existing issues](https://github.com/scenario-labs/unreal-plugin/issues)
first. For a question, open a blank issue with a title starting with "Question:".

Before filing a bug, collect:

- The Unreal Engine version (Help > About Unreal Editor) and your operating
  system.
- The plugin version from Edit > Plugins (search "Scenario"), and whether you
  installed it from Fab, a GitHub release zip or a source copy.
- The lane or workflow, model and steps to reproduce, what you expected and
  what happened.
- Relevant lines from the Output Log (Window > Output Log, filter on
  `LogScenario`).

Public issues and attachments are visible to everyone. Never include an API
key, an API secret, an OAuth or agent token, a signed download URL or
confidential project files.

## Account, billing, credits, API keys and security

Keep these matters out of public issues. Write to
[support@scenario.com](mailto:support@scenario.com) or use in-app support at
[app.scenario.com](https://app.scenario.com). Report security vulnerabilities as
described in [SECURITY.md](SECURITY.md).

## What to expect

Plugin issues are handled on a best-effort basis, without a response-time
commitment. Support for your Scenario account or subscription goes through the
Scenario channels above.
